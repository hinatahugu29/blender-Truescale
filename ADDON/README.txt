■ カスタムシーン版について

この版は、制作環境ごとに異なるBlenderのScene Unit Scaleを
そのシーンから自動取得して実寸換算へ使用する実験版です。

例:
- Unit Scale 0.001 → 1 Blender Unit = 1 mm
- Unit Scale 0.01  → 1 Blender Unit = 10 mm

シーン設定そのものは変更しません。

また、元モデルのObject Scaleが1.0でない場合も、
matrix_worldを使ったワールド寸法を実寸計算へ反映します。
そのため、Scale 0.01などの未適用スケールでも、
見た目のワールド寸法を基準に型紙寸法を計算します。

ただし、Scene Unit Scaleとモデルの実寸解釈そのものが
制作時点から食い違っているデータを自動判定・修正することはできません。
「そのシーンでBlenderが示している実寸」を基準にする版です。


■ v1.5.3 型紙ID配置の改善

自動の型紙ID配置を、単純な島の中心基準から
「実際に面が存在し、文字の領域が島の中へ収まりやすい場所」を
探索する方式へ変更しました。

- コの字型などの凹形状
- 中央に穴があるリング状形状
- 細長い形状
- 太い部分と細い部分が混在する形状

などで、IDが空洞や輪郭外へ出にくくなっています。

候補が複数ある場合は輪郭からの余裕を優先し、
同程度なら自動矢印の中心線から少し離れた位置を優先します。

極端に細く、設定された文字サイズそのものが収まらない型紙では、
完全に収まる位置が存在しない場合があります。
その場合も、空洞ではなく実際の型紙面上で最も余裕のある位置を選びます。



Blenderでシームを設定した3Dモデルから、
組み立て情報付きの実寸型紙を作成するためのBlender Extensionです。

コスプレ造形、衣装、立体物などの展開図作成を想定しています。


■ 対応環境

- Blender 4.2以降
- Blender 5.2系で動作確認
- 入力モデルはMeshオブジェクト


■ インストール

1. Blenderを開きます。
2. 編集 > プリファレンス > エクステンション を開きます。
3. 右上メニューから「ディスクからインストール」を選びます。
4. 「型紙ヘルパー_カスタムシーン_ベータ版_v1.5.6.zip」を選択します。
5. 3DビューのNパネルに「型紙ヘルパー」が追加されます。


■ 基本の使い方

1. 元モデルにシームを設定します。
   Blender標準機能、または別アドオン「楽シーム」などを使用できます。

2. シーム付きMeshを選択します。

3. Nパネル > 型紙ヘルパー > 「モデルの読み込み」を押します。

4. 「型紙を作成 / 更新」を押します。

5. 必要に応じて、合印・ID・矢印・メモを設定します。

6. 自動レイアウト、または手動レイアウトで配置を整えます。

7. 印刷プレビューで確認します。

8. 「実寸PNGを書き出し（300dpi）」から出力します。


■ 1. モデルと型紙

【モデルの読み込み】
現在選択しているシーム付きMeshを読み込みます。

【元モデルを表示 / 非表示】
元の3Dモデルだけを表示・非表示にします。

【軽量ビュー】
高密度メッシュでの表示負荷を抑えます。
通常はON推奨です。

【型紙を作成 / 更新】
シームを使って実寸型紙を生成します。
元モデルそのものは変更しません。

【型紙を削除】
生成した型紙だけを削除します。
元モデルのシームは保持されます。


■ 2. マーキング

【合印】
- 自動 / なし を選択できます。
- 自動では2分割、3分割、4分割を選択できます。
- シーム全体の長さを基準に合印を配置します。
- 合印の長さ、太さ、色を調整できます。
- 手動追加もできます。

【型紙ID・接続先】
- 各型紙へ自動でIDを付けます。
- A/B/C形式、または1/2/3形式を選択できます。
- 接続する辺には相手側の型紙IDを自動表示します。

【上方向矢印】
- X / Y / Z軸から上方向を指定します。軸方向はBlender右上のXYZギズモと同じグローバル軸です。
- 各型紙へ上方向矢印を自動配置します。
- 水色の方向ガイドはViewport確認用です。
- 水色ガイドはPNGには出力されません。

【対応確認・メモ】
- 「対応確認を開始」で元モデルと型紙の対応を確認できます。
- 左クリックで対応するアイランドをハイライトします。
- 「対応ハイライトをクリア」で解除できます。

型紙メモ:
- 「型紙にメモを追加」→ 型紙上をクリック → 文字入力、の順で追加します。
- 対応確認中は型紙を短時間に2回クリックしてもメモ追加できます。
- 文字入力後は、その場でマウスを動かして回転できます。
- 左クリックで回転を確定します。
- 既存メモはクリックしてRキーで回転できます。
- X / Delete / Backspaceで選択中のメモを削除できます。
- メモは300dpi PNGにも出力されます。
- 配置後のメモ移動には対応していません。


■ 3. レイアウト・印刷

【用紙設定】
対応サイズ:
A5 / A4 / A3 / A2 / A1 / A0 / B5 / B4

向き:
縦 / 横 / 自動

用紙ガイドはViewport表示のみです。

【自動レイアウト】
- 型紙を実寸のまま自動配置します。
- 必要に応じて90度回転を使います。
- 用紙へ収めるための自動縮小は行いません。

【手動で調整】
- 型紙アイランドを手動配置できます。
- 面を選択してGキーで移動します。
- 手動調整中は軽量化のためマーキング表示を一時停止します。
- 「レイアウト確定」で再計算・再表示します。

【印刷プレビュー】
- 白い用紙と黒い印刷輪郭で最終状態を確認できます。
- プレビュー中は元モデルを自動で非表示にします。
- プレビュー終了時は元の表示状態へ戻します。

【実寸PNGを書き出し（300dpi）】
PNGには以下を出力します。
- 型紙外周
- 合印
- 型紙ID
- 接続先ID
- 上方向矢印
- 型紙メモ

水色の方向ガイドは出力しません。


■ 作業終了

【作業終了・型紙を片付ける】
生成した型紙と型紙ヘルパー側のマーキングを片付けます。

元モデルに設定したBlenderのシームは削除しません。


■ 注意事項

- 本アドオンはUV展開を利用して3D形状を2Dへ展開します。
- UV展開の性質上、元モデルの形状・ポリゴン構成・シーム位置などによって、展開結果には誤差や歪みが生じる場合があります。
- 「実寸」はBlender上の寸法を基準に出力するという意味であり、展開後の形状が実物と完全一致することを保証するものではありません。
- 布、フォーム、合皮など各素材の伸縮率・厚み・圧縮・曲げやすさ・クセなどの物性は考慮していません。
- 縫い代、接着代、素材厚による補正なども自動では加味されません。
- 出力される型紙は完成形そのものではなく、試作・調整のための「たたき台」として使用してください。
- 実制作前に、紙や安価な素材などで試作し、必要に応じて寸法や形状を調整することを推奨します。
- 型紙の実寸を優先するため、自動縮小は行いません。
- 高密度メッシュでは処理が重くなる場合があります。
- 高密度モデルでは「軽量ビュー」をONにしてください。
- 手動レイアウト中は合印・ID・矢印・メモを一時非表示にします。
- 型紙メモは配置後の回転と削除に対応しています。移動には対応していません。
- 複雑な形状やシーム構成では、意図した展開結果にならない場合があります。
- 元モデルのシームは型紙削除・作業終了後も保持されます。


■ 楽シームについて

「楽シーム」は別アドオンです。
型紙ヘルパーに必須ではありません。

Blender標準機能でシームを設定したモデルでも、
そのまま型紙ヘルパーを使用できます。

■ v1.5.4 自動矢印の島内配置を改善

型紙IDと同様に、自動矢印も単純な島の中心ではなく、
実際に面が存在する場所へ収まる位置を探索する方式へ変更しました。

- リング状で中央が空洞の型紙
- コの字などの凹形状
- 細長い型紙
- 輪郭が大きくえぐれた型紙

でも、矢印の軸と矢尻が空洞・輪郭外へ出にくくなっています。

矢印の方向は従来どおり選択したBlenderグローバルX/Y/Zを基準にします。
まず設定された矢印長を維持したまま収まる位置を探し、
物理的に収まる場所がない場合だけ段階的に短くして島内へ収めます。


■ v1.5.5 自動矢印配置の軽量化

v1.5.4で追加した島内安全配置の探索が、複雑な型紙で重くなる問題を修正しました。

- 候補グリッドを19×19から7×7へ削減
- 高密度Meshでは全Face中心を調べず最大約24点へ間引き
- 島の輪郭セグメントを候補ごとに再計算せず使い回し
- 矢印軸・矢尻の途中判定サンプル数を削減
- 長さ短縮の再探索回数を削減

リング・コの字などで空洞や輪郭外を避ける基本挙動は維持しています。


■ v1.5.6 カスタム用紙サイズ

用紙サイズに「カスタム」を追加しました。

カスタム選択時は、
- 幅（mm）
- 高さ（mm）

を直接指定できます。

指定したサイズは、
- 用紙ガイド
- 自動レイアウト
- 印刷プレビュー
- 300dpi PNG書き出し

のすべてで共通して使用されます。

カスタム用紙では「幅 × 高さ」を入力値どおりに使用し、
縦/横の自動入れ替えは行いません。

例:
600 × 900 mm
1000 × 1200 mm
450 × 1800 mm
など、A判/B判以外の任意サイズを使用できます。

非常に大きなカスタム用紙を300dpi PNGへ出力すると、
画像サイズ・メモリ使用量が大きくなるため、
従来どおり160,000,000ピクセルを超える出力は停止します。
