# Truescale

Blender のモデルを、**実寸のまま紙へ出す**ための Blender アドオンです。
コスプレ造形、衣装、紙模型、立体物の制作を想定しています。

```
Blender のモデル ──┬─→ 型紙（展開図）  ── PDF / PNG ─→ 切って組む
                  └─→ 三面図シート     ── PNG ──────→ 大きさを伝える
```

対象は Blender 4.2 以降、Mesh オブジェクトです。

---

## 何ができるか

### 型紙（Unfold）

シームを入れたモデルを、**縮尺を掛けずに**平面へ開きます。

- 実寸の型紙メッシュを作る（1 BU が何ミリかは自分で決められます）
- 合印・番号・文字・上方向の矢印・型紙ID を置く
- **縫い代**（輪郭を外へ広げた裁断線）と**糊代**（貼り合わせる辺の台形）
- 紙に並べる。1枚に入らなければ**複数枚に分割**し、貼り合わせの目印を付ける
- PDF（1ファイル・ベクタ）または PNG（300dpi）で書き出す
- 型紙を**普通のメッシュとして確定**して残す

**縮めません。** 収まらないときは縮小せず、分割するか、収まらないと言います。
黙って数パーセント縮んだ型紙は、切ってから気付くことになるためです。

### 三面図（Draft）

モデルを囲む直方体を作り、その**外形寸法**を画面に出します。

- 箱と寸法を 3D ビューへ重ねて表示（モデルを編集すると追従）
- 正面・上面・側面・任意の4分割ビュー
- 三面を 1 枚の用紙へ、指定した縮尺（1:1、1:2…）で並べた PNG
- 1 面だけの実寸 PNG（300dpi）

作るための図ではなく、**大きさを人に伝えるための図**です。

## 入れかた

1. `dist/truescale-0.3.0.zip` を用意します（無ければ下の「作りかた」）。
2. Blender の **編集 › プリファレンス › エクステンション** を開きます。
3. 右上のメニューから **ディスクからインストール** を選びます。
4. ZIP を選びます。
5. 3D ビューの N パネルに **Truescale** タブが増えます。

型紙と三面図は同じタブの中に、別々のパネルとして並びます。
使わないほうは畳んでおけます。

- [変更履歴](CHANGELOG.md) — 版ごとの変更点

```bash
# 静的チェック（15項目）
python tools/check_addon.py truescale/unfold/__init__.py truescale/draft/__init__.py

# Blender 非依存のテスト
python tools/test_pure.py

# ヘッドレステスト
blender --background --factory-startup --python tools/test_headless.py

# 上の3つをまとめて
tools/run_tests.cmd

# 配布用 ZIP を作る
python tools/build.py
```

`tools/build_docs.py` は、`docs/*.md` から 1 枚の HTML マニュアルを作ります。
HTML は生成物なので、直に書き換えないでください。元は Markdown です。
