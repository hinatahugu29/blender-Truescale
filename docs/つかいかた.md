## 型紙をつくる

パネルは番号の順に上から並んでいます。**1 → 2 → 3 → 4** をなぞれば終わります。
番号の付いていない区画（「印をつける」「縫い代・糊代」など）は任意です。

### 0. 実寸の基準（最初に一度だけ）

いちばん上の **実寸の前提** を開きます。畳んであります。

| 決め方 | どういうとき |
|---|---|
| シーンに従う（既定） | Blender の Unit Scale が正しく設定されている |
| このアドオンで指定 | シーン側を触りたくない。1 BU を何ミリとして扱うかを直に入れる |

**編集モードで辺を1本選び「選択した辺を基準に実寸を決める」** を押すと、
その辺を何ミリにしたいかを入れるだけで基準が決まります。
「この筒の直径は 80mm のはず」が分かっていれば、これがいちばん確実です。

一度決めれば、ふつうは触りません。三面図側も同じ基準で測ります。

### 1. 読み込む

**モデルの読み込み** で対象を決めます。選択しているメッシュが対象になります。

続けて **シーム編集** で、どこで切り開くかを入れます。
編集モードで辺を選び、「シームを入れる」。外すときは「外す」。

**対称 X / Y / Z** を入れておくと、反対側の辺にも同時に入ります。
左右対称の衣装や造形では、これでほぼ半分の手間になります。

> シームの出来がそのまま型紙の形になります。ここを間違えると後の工程では
> 取り返せないので、いちばん時間をかけてよいところです。

### 2. 型紙にする

**型紙を作成 / 更新** を押すと、実寸の平面メッシュが `<名前>_展開図` として作られます。

- **元モデルを非表示** — 型紙だけを見たいとき
- **型紙を表示して選択** — 型紙を選び直す
- **軽量ビュー** — 元モデル側の重い表示を止める。動作が重いときに
- **型紙を削除** — 作り直すとき

このあと、必要なら次の2つを足します。どちらも**型紙を大きくする**ので、
紙に並べる前にやってください。

#### 縫い代・糊代（任意）

**縫い代** … 輪郭を外へ一定量ひろげます。外側の実線が裁断線、
元の輪郭が破線の縫い線になります。布向きです。

**糊代（のりしろ）** … 貼り合わせる辺に、折って糊を付けるための台形を出します。
紙模型向きです。

- シームの辺**すべて**に、**片側だけ**付きます（両側に付けたら二重になります）
- **根元の破線は折り線です。切らないでください**
- 置けない辺では自動で細くなり、それでも入らない辺には付きません
- **どちら側に付くかは自動で決まります。** その決め方は内部の順序に
  よるもので、画面の A / B / C とは関係がありません
- 辺ごとの調整ができます。元メッシュを編集モードにして辺を選び、
  「消す」「戻す」「**反対側へ移す**」

> 消した記録も入れ替えた記録も、**元メッシュ**に残ります。
> 型紙を作り直しても残ります。

「この面には糊代を出したくない」というときは **反対側へ移す** を使います。
移した先に置けない（隣とぶつかる）ときは、元の側のままになります。
押すと、どの型紙へ移ったかが画面下に出ます（「A → C」）。

**どの辺にどの指示が入っているかは、元モデルのシーム線の色で分かります。**

| 色 | 状態 |
|---|---|
| 赤 | そのまま。糊代は自動で付きます |
| 灰 | 糊代を消した辺 |
| 橙 | 反対側へ移した辺 |

画面での色は変えられます。**刷るときは黒**になります（白黒で刷っても
実線と破線で区別が付くように）。

#### 印をつける（任意）

畳んであります。必要になったときだけ開いてください。

| | |
|---|---|
| 合印 | 縫い合わせる位置の目印。シームの辺から自動で作ることもできます |
| 型紙番号 | 連番を置く |
| 文字 | 任意の文字を置く |
| 上方向矢印 | 生地の向き・柄の向き |
| 型紙ID | 島ごとに A / B / C…（自動）。接続先の記号も出ます |
| 型紙メモ | 型紙に直接書く文字 |

**対応確認** を使うと、型紙の島と元モデルの面がどう対応しているかを
色で確かめられます。

型紙IDの **元モデルにも表示** を入れると、同じ記号が元モデルの面にも出ます。
切ったピースがモデルのどこかを探すときに使います。

- 見ている側を向いた面の記号だけが出ます（裏側の記号は透けて見えません）
- **シームを変えて型紙を作り直すと、記号が付け直されます。** 記号は元モデルの
  面の順で決まるので、島が1つ分かれると、それより後ろの記号がずれます。
  刷った型紙と見比べるときは、刷り直してください
- 元モデルの面の向き（法線）が裏返っていると、記号が隠れたり沈んだりします

### 3. 紙に並べる

用紙と向きを選ぶと、**実寸・必要な枚数・収まる用紙**がその場で出ます。

```
型紙 568 × 251 mm を 210×297 mm を 3×1 = 3 枚
A2 なら1枚で収まります
```

**用紙ガイドを表示** で、紙の切れ目が 3D ビューに出ます。

#### 紙のとりかた

| | |
|---|---|
| 用紙の余白 (mm) | プリンタが刷れない縁の幅。多めに取ってください |
| 型紙のまわり (mm) | 型紙とガイドの枠の間に空ける余白。鋏を入れる余地 |
| 重ねしろ (mm) | 隣の紙と重ねて貼る幅。**分割するときだけ出ます** |

上の2つは、1枚に収まるときも効いています。
「なぜか思ったより小さく刷られる」と感じたら、まずここを見てください。

#### 並べかた

- **自動レイアウト** — 枚数がいちばん少なくなるように詰めます
- **手動で調整** — 編集モードに入り、島を選んで G で動かせます。
  印・寸法・縫い代も一緒に動きます。終わったら **レイアウト確定**

### 4. 出す / 残す

いちばん上に、展開でどれだけ縮んだかが出ます。

```
縮み 中央 4.1% / 大きいところ 12.3%
```

**「大きいところ」が 5% を超えたら、シームを足すか検討してください。**
超えなければ何も言いません。詳しくは「こまったとき」の
[型紙の形が歪む](こまったとき.md) を見てください。

**印刷プレビュー** で、刷ったときの見た目を確認できます。

**形式** を選んで **実寸で書き出し（300dpi）**。

| | |
|---|---|
| PDF | 何枚に分かれても**1ファイル**。線のまま残るので拡大しても粗くならない |
| PNG | 1枚ずつの画像。他のソフトへ持ち込むとき。分割すると枚数分できます |

分割したときは、各ページに次のものが入ります。

- **受け持ち範囲の枠** — 隣の紙と合わせる線
- **合わせの印**（十字と菱形） — 重ねると隣の紙の同じ印とぴたり重なります
- **実寸の目盛り** — 定規を当てて、縮んでいないか確かめるため
- **タイル名**（1-A、2-A…）と総数

> **印刷ダイアログで「用紙に合わせる」を選ばないでください。**
> 数パーセント縮み、目では気付けません。「実際のサイズ」「100%」を選んでください。
> 刷ったら必ず目盛りに定規を当てて確かめてください。

#### 型紙を残したいとき

**型紙を確定して残す** を押すと、アドオンから切り離した普通のメッシュになります。

- マーキングは消えます
- 「作業終了・型紙を片付ける」でも消えなくなります
- 元メッシュが同じなら、あとから同じ型紙を作り直せます

**作業終了・型紙を片付ける** は、確定していない型紙を消して元の表示に戻します。

## 三面図をつくる

### 1. サイズ表示

対象のメッシュを選んで **BOX＋寸法を作成**。

モデルを囲む直方体ができ、その**外形寸法**が 3D ビューに出ます。
**自動追従** を入れておくと、モデルを編集したとき箱も付いてきます。

> 測っているのは**箱**であって、モデルの形そのものではありません。
> 凹凸のある形でも「全体で何ミリか」を読めるようにするためです。

寸法の文字は手で書き換えられます（「およそ」「max」など）。
空にすると実測値に戻ります。

### 2. 枠線・文字

枠の出しかた（BOX / 寸法線のみ / なし）、色、太さ、文字の大きさと色。

**暗所表示** は、背景を暗くして箱の枠を目立たせる表示です。

### 3. 図面ビュー

**三面＋任意ビュー** で4分割にします。正面・上面・側面のズームは揃います。

**正面 / 上面 / 側面 / 任意** で1つのビューへ切り替えられます。
**元の表示に戻す** で作業前の状態へ戻ります。

### 4. 出力

**用紙・向き・縮尺** を決めます。縮尺は 1:1、1:2、1:5、1:10、または任意の 1:N。

| | |
|---|---|
| 三面図シートを書き出し | 三面を1枚の用紙へ並べた PNG。縮尺が紙に書き込まれます |
| 三面図シートをプレビュー | 書き出さずに確認 |
| 上面 / 前面 / 側面 / 任意 | 1面だけの実寸 PNG（300dpi） |
| 3面まとめてPNG | 3面を別々の PNG で |

三面の縮尺は必ず揃います。面ごとに「紙に収まるように」倍率を変えると、
図面として読めなくなるためです。収まらなければ、縮尺を落とすよう案内が出ます。

**寸法位置の微調整** を開くと、文字の位置を面ごと・軸ごとにずらせます。

## 覚えておくとよいこと

**実寸は嘘をつけません。** 型紙側は縮尺を掛けないので、刷ったものに定規を
当てれば正しいかどうかがすぐ分かります。目盛りは必ず確かめてください。

**シームを直したら型紙も作り直しです。** 「型紙を作成 / 更新」を押し直して
ください。糊代を消した記録と、元モデルに置いた印は残ります。

**元モデルを作り直す（リトポロジーする）と、シームも糊代の設定も失われます。**
辺の番号が変わるためです。
