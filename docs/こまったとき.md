## 刷ったものが合わない

### 定規を当てると寸法が違う

**まず印刷設定を疑ってください。** ここが原因の大半です。

印刷ダイアログの「用紙に合わせる」「フィット」を選ぶと、数パーセント縮みます。
**「実際のサイズ」「100%」「倍率 100%」** を選んでください。

分割して刷ったときは、各ページの下に実寸の目盛りが入っています。
そこに書いてある数値（100MM など）と実測が合っているか確かめてください。

### 実寸そのものが違う

型紙パネルの **実寸の前提** を確認してください。

- 「シーンに従う」のとき … Blender の Unit Scale が意図どおりか
- 「このアドオンで指定」のとき … 1 BU のミリ数が正しいか

分からないときは、**編集モードで長さの分かっている辺を1本選び、
「選択した辺を基準に実寸を決める」** が確実です。

三面図側も同じ基準で測ります。片方だけ違う、ということは起きません。

### 分割した紙がつながらない

- 各ページの**枠線**を隣の紙と合わせてください。紙の端ではありません
- **合わせの印**（十字と菱形）は、重なった帯の中央にあります。
  重ねたときに隣の紙の同じ印とぴたり重なります
- 線は受け持ち範囲より少し外まで描いてあります。線が続いていることを
  目で確かめながら貼れます
- **全ページが同じ倍率で刷れているか**を、それぞれの目盛りで確かめてください。
  1枚だけ設定が違うことがあります

## 型紙がうまく出ない

### 「用紙に収まりません」と出る

縮めません。次のどれかです。

- 用紙を大きくする（「A2 なら1枚で収まります」という案内が出ます）
- 分割して刷る（3×1 = 3枚、のように出ます）
- シームを増やして、島を小さく分ける
- 「用紙のまわり」「重ねしろ」を減らす

### 島の間隔が広すぎる／狭すぎる

「紙に並べる」の **アイランド間隔** を変えると、その場で並べ直します。

### 型紙の形が歪む

UV 展開の性質上、元の形とシームの位置によって歪みます。
円錐や球のように、そもそも平面へ展開できない形では必ず起きます。

**どれだけ歪んだかは「4. 出す / 残す」に出ます。**

```
縮み 中央 4.1% / 大きいところ 12.3%
```

「大きいところ」は、縮みの大きいほうから 5% の辺です。最大値は
出していません。1本だけ極端な辺があっても実害は小さいのに、
数字だけが独り歩きするためです。

| 大きいところ | 見かた |
|---|---|
| 5% 未満 | 気にしなくて大丈夫です |
| 5〜15% | 布ならいせ込みで吸収できます。紙ならシームを足したい |
| 15% 超 | シームが足りません。曲面を1枚で展開しようとしています |

**縮む側にしか外れません。** 平面へ写す以上、傾いた辺は短くなる
ためです。組んだときに出るのは「少し足りない」で、余ることは
ありません。

シームを増やして、1つの島を小さくすると軽くなります。

### 印や文字が消えた

- **手動で調整**（レイアウト編集）の最中は、控えた印をずらして描いています。
  頂点を足したり消したりすると、対応が取れなくなるため表示を止めます
- 「型紙を確定して残す」を押すと、マーキングは消えます（仕様です）

### 動作が重い

- **軽量ビュー** を入れてください。元モデル側の重い表示を止めます
- 元モデルを非表示にすると、そちら側の計算をまるごと飛ばします
- 面数の多いモデル（数百面の島）では、糊代の計算に数百ミリ秒かかります。
  一度計算すれば、形と設定が変わるまで作り直しません

## 糊代・縫い代

### 糊代が付かない辺がある

次のどれかです。

- **相手がいない辺** … 元の立体の縁（開いた口など）。貼り合わせる先が
  無いので付きません
- **場所がない** … 隣の島やタブとぶつかる。自動で細くし、下限まで
  細くしても入らなければ諦めます。無理に置くと、切ったとき型紙自体を
  切ってしまうためです
- **手で消してある** … 「全部戻す」で戻ります

### 糊代が思っていたのと逆の型紙に付く

どちら側に付くかは自動で決まります。その決め方は内部の順序による
もので、**画面に出ている A / B / C とは関係がありません**。

元メッシュを編集モードにしてその辺を選び、**反対側へ移す** を押して
ください。押すと、どの型紙へ移ったかが画面下に出ます（「A → C」）。
移した先に置けない（隣とぶつかる）ときは、元の側のままになり、
移り先も出ません。

### どの辺を触ったか分からなくなった

**元モデルのシーム線の色**を見てください。

| 色 | 状態 |
|---|---|
| 赤 | そのまま |
| 灰 | 糊代を消した辺 |
| 橙 | 反対側へ移した辺 |

全部戻したいときは「全部戻す」です。

詰まったレイアウトでは、ぶつかって付かないタブが増えます。
「アイランド間隔」を広げると付きやすくなります。

### 糊代を切ってしまった

**根元の破線は折り線です。** 切るのは台形の外側の3辺だけです。

画面では色で分かれています（既定は裁断線＝青緑、折り線＝桃）。
**刷ると両方とも黒**になり、実線と破線で区別します。

## 三面図

### 書き出したあと画面が変わっている

戻るはずです。戻っていなければ不具合なので、どの操作の後かを添えて
教えてください。

視点・背景・オーバーレイ・BOX と寸法の表示は、書き出しの間だけ変わり、
終われば必ず元へ戻るようにしてあります。

### 画像に N パネルやツールバーが写る

写らないように切り抜いています。写っていれば不具合です。

### 「用紙が大きすぎます」と出る

カスタム用紙が大きすぎます。下限の解像度（96dpi）でも画素数が上限を
超える大きさ（おおよそ 1m × 2.5m 以上）では、メモリが足りなくなるため
断ります。用紙を小さくしてください。

### 三面図が用紙に収まらない

縮尺の N を大きくしてください（1:2 → 1:5 など）。N が大きいほど図は
小さくなります。用紙を大きくしても構いません。

### 寸法の文字が図に重なる

**寸法位置の微調整** を開くと、面ごと・軸ごとに位置をずらせます。
**文字位置をリセット** で戻ります。

## いまできないこと

### 型紙

- **素材の厚みの補正** — 厚みのぶんの寸法調整は入りません
- **SVG 出力** — PDF と PNG のみです
- **短い辺に糊代を付けない下限の指定** — 曲面のシームでは辺ごとに
  1枚ずつ付くので、分割数の多いモデルでは小さなタブが並びます

### 三面図

- **部分の寸法** — 出せるのは外接直方体の縦横高さだけです。
  「穴は左端から 40mm」のような寸法は表現できません
- **線画** — ビューポートを撮っているので、陰影のついた絵になります。
  隠線処理・断面・公差はありません
- **複数用紙への分割** — 1枚に収める前提です（縮尺を落としてください）

### 共通

- **元モデルを作り直すと設定が失われる** — リトポロジーすると辺の番号が
  変わるため、シームも糊代の設定も失われます
- **Blender 4.1 以前では使えません** — 拡張機能の仕組みが 4.2 からのためです。
  4.2 LTS と 5.2 で動作を確かめています

## 不具合を報告するとき

次があると調べやすくなります。

- どの操作を押したか（パネルのどの区画か）
- 画面のスクリーンショット
- Blender のコンソールに出たメッセージ（**ウィンドウ › システムコンソールを切り替え**）
- 可能なら .blend ファイル
