Truescale マニュアル

Blender のモデルを、実寸のまま紙へ出すためのアドオンです。

つかいかた

3D ビューの N パネル、Truescale タブを開いてください。 「型紙」と「三面図」が別々のパネルとして並んでいます。

  • 型紙をつくる
  • 三面図をつくる

型紙をつくる

パネルは番号の順に上から並んでいます。1 → 2 → 3 → 4 をなぞれば終わります。 番号の付いていない区画（「印をつける」「縫い代・糊代」など）は任意です。

0. 実寸の基準（最初に一度だけ）

いちばん上の 実寸の前提 を開きます。畳んであります。

決め方どういうとき
シーンに従う（既定）Blender の Unit Scale が正しく設定されている
このアドオンで指定シーン側を触りたくない。1 BU を何ミリとして扱うかを直に入れる

編集モードで辺を1本選び「選択した辺を基準に実寸を決める」 を押すと、 その辺を何ミリにしたいかを入れるだけで基準が決まります。 「この筒の直径は 80mm のはず」が分かっていれば、これがいちばん確実です。

一度決めれば、ふつうは触りません。三面図側も同じ基準で測ります。

1. 読み込む

モデルの読み込み で対象を決めます。選択しているメッシュが対象になります。

続けて シーム編集 で、どこで切り開くかを入れます。 編集モードで辺を選び、「シームを入れる」。外すときは「外す」。

対称 X / Y / Z を入れておくと、反対側の辺にも同時に入ります。 左右対称の衣装や造形では、これでほぼ半分の手間になります。

シームの出来がそのまま型紙の形になります。ここを間違えると後の工程では 取り返せないので、いちばん時間をかけてよいところです。

2. 型紙にする

型紙を作成 / 更新 を押すと、実寸の平面メッシュが <名前>_展開図 として作られます。

  • 元モデルを非表示 — 型紙だけを見たいとき
  • 型紙を表示して選択 — 型紙を選び直す
  • 軽量ビュー — 元モデル側の重い表示を止める。動作が重いときに
  • 型紙を削除 — 作り直すとき

このあと、必要なら次の2つを足します。どちらも型紙を大きくするので、 紙に並べる前にやってください。

縫い代・糊代（任意）

縫い代 … 輪郭を外へ一定量ひろげます。外側の実線が裁断線、 元の輪郭が破線の縫い線になります。布向きです。

糊代（のりしろ） … 貼り合わせる辺に、折って糊を付けるための台形を出します。 紙模型向きです。

  • シームの辺すべてに、片側だけ付きます（両側に付けたら二重になります）
  • 根元の破線は折り線です。切らないでください
  • 置けない辺では自動で細くなり、それでも入らない辺には付きません
  • どちら側に付くかは自動で決まります。 その決め方は内部の順序に よるもので、画面の A / B / C とは関係がありません
  • 辺ごとの調整ができます。元メッシュを編集モードにして辺を選び、 「消す」「戻す」「反対側へ移す」
消した記録も入れ替えた記録も、元メッシュに残ります。 型紙を作り直しても残ります。

「この面には糊代を出したくない」というときは 反対側へ移す を使います。 移した先に置けない（隣とぶつかる）ときは、元の側のままになります。 押すと、どの型紙へ移ったかが画面下に出ます（「A → C」）。

どの辺にどの指示が入っているかは、元モデルのシーム線の色で分かります。

色状態
赤そのまま。糊代は自動で付きます
灰糊代を消した辺
橙反対側へ移した辺

画面での色は変えられます。刷るときは黒になります（白黒で刷っても 実線と破線で区別が付くように）。

印をつける（任意）

畳んであります。必要になったときだけ開いてください。

合印縫い合わせる位置の目印。シームの辺から自動で作ることもできます
型紙番号連番を置く
文字任意の文字を置く
上方向矢印生地の向き・柄の向き
型紙ID島ごとに A / B / C…（自動）。接続先の記号も出ます
型紙メモ型紙に直接書く文字

対応確認 を使うと、型紙の島と元モデルの面がどう対応しているかを 色で確かめられます。

3. 紙に並べる

用紙と向きを選ぶと、実寸・必要な枚数・収まる用紙がその場で出ます。

型紙 568 × 251 mm を 210×297 mm を 3×1 = 3 枚
A2 なら1枚で収まります

用紙ガイドを表示 で、紙の切れ目が 3D ビューに出ます。

紙のとりかた
用紙の余白 (mm)プリンタが刷れない縁の幅。多めに取ってください
型紙のまわり (mm)型紙とガイドの枠の間に空ける余白。鋏を入れる余地
重ねしろ (mm)隣の紙と重ねて貼る幅。分割するときだけ出ます

上の2つは、1枚に収まるときも効いています。 「なぜか思ったより小さく刷られる」と感じたら、まずここを見てください。

並べかた
  • 自動レイアウト — 枚数がいちばん少なくなるように詰めます
  • 手動で調整 — 編集モードに入り、島を選んで G で動かせます。 印・寸法・縫い代も一緒に動きます。終わったら レイアウト確定

4. 出す / 残す

いちばん上に、展開でどれだけ縮んだかが出ます。

縮み 中央 4.1% / 大きいところ 12.3%

「大きいところ」が 5% を超えたら、シームを足すか検討してください。 超えなければ何も言いません。詳しくは「こまったとき」の 型紙の形が歪む を見てください。

印刷プレビュー で、刷ったときの見た目を確認できます。

形式 を選んで 実寸で書き出し（300dpi）。

PDF何枚に分かれても1ファイル。線のまま残るので拡大しても粗くならない
PNG1枚ずつの画像。他のソフトへ持ち込むとき。分割すると枚数分できます

分割したときは、各ページに次のものが入ります。

  • 受け持ち範囲の枠 — 隣の紙と合わせる線
  • 合わせの印（十字と菱形） — 重ねると隣の紙の同じ印とぴたり重なります
  • 実寸の目盛り — 定規を当てて、縮んでいないか確かめるため
  • タイル名（1-A、2-A…）と総数
印刷ダイアログで「用紙に合わせる」を選ばないでください。 数パーセント縮み、目では気付けません。「実際のサイズ」「100%」を選んでください。 刷ったら必ず目盛りに定規を当てて確かめてください。
型紙を残したいとき

型紙を確定して残す を押すと、アドオンから切り離した普通のメッシュになります。

  • マーキングは消えます
  • 「作業終了・型紙を片付ける」でも消えなくなります
  • 元メッシュが同じなら、あとから同じ型紙を作り直せます

作業終了・型紙を片付ける は、確定していない型紙を消して元の表示に戻します。

三面図をつくる

1. サイズ表示

対象のメッシュを選んで BOX＋寸法を作成。

モデルを囲む直方体ができ、その外形寸法が 3D ビューに出ます。 自動追従 を入れておくと、モデルを編集したとき箱も付いてきます。

測っているのは箱であって、モデルの形そのものではありません。 凹凸のある形でも「全体で何ミリか」を読めるようにするためです。

寸法の文字は手で書き換えられます（「およそ」「max」など）。 空にすると実測値に戻ります。

2. 枠線・文字

枠の出しかた（BOX / 寸法線のみ / なし）、色、太さ、文字の大きさと色。

暗所表示 は、背景を暗くして箱の枠を目立たせる表示です。

3. 図面ビュー

三面＋任意ビュー で4分割にします。正面・上面・側面のズームは揃います。

正面 / 上面 / 側面 / 任意 で1つのビューへ切り替えられます。 元の表示に戻す で作業前の状態へ戻ります。

4. 出力

用紙・向き・縮尺 を決めます。縮尺は 1:1、1:2、1:5、1:10、または任意の 1:N。

三面図シートを書き出し三面を1枚の用紙へ並べた PNG。縮尺が紙に書き込まれます
三面図シートをプレビュー書き出さずに確認
上面 / 前面 / 側面 / 任意1面だけの実寸 PNG（300dpi）
3面まとめてPNG3面を別々の PNG で

三面の縮尺は必ず揃います。面ごとに「紙に収まるように」倍率を変えると、 図面として読めなくなるためです。収まらなければ、縮尺を落とすよう案内が出ます。

寸法位置の微調整 を開くと、文字の位置を面ごと・軸ごとにずらせます。

覚えておくとよいこと

実寸は嘘をつけません。 型紙側は縮尺を掛けないので、刷ったものに定規を 当てれば正しいかどうかがすぐ分かります。目盛りは必ず確かめてください。

シームを直したら型紙も作り直しです。 「型紙を作成 / 更新」を押し直して ください。糊代を消した記録と、元モデルに置いた印は残ります。

元モデルを作り直す（リトポロジーする）と、シームも糊代の設定も失われます。 辺の番号が変わるためです。

こまったとき

v0.2.0 時点。

  • 刷ったものが合わない
  • 型紙がうまく出ない
  • 糊代・縫い代
  • 三面図
  • いまできないこと

刷ったものが合わない

定規を当てると寸法が違う

まず印刷設定を疑ってください。 ここが原因の大半です。

印刷ダイアログの「用紙に合わせる」「フィット」を選ぶと、数パーセント縮みます。 「実際のサイズ」「100%」「倍率 100%」 を選んでください。

分割して刷ったときは、各ページの下に実寸の目盛りが入っています。 そこに書いてある数値（100MM など）と実測が合っているか確かめてください。

実寸そのものが違う

型紙パネルの 実寸の前提 を確認してください。

  • 「シーンに従う」のとき … Blender の Unit Scale が意図どおりか
  • 「このアドオンで指定」のとき … 1 BU のミリ数が正しいか

分からないときは、編集モードで長さの分かっている辺を1本選び、 「選択した辺を基準に実寸を決める」 が確実です。

三面図側も同じ基準で測ります。片方だけ違う、ということは起きません。

分割した紙がつながらない

  • 各ページの枠線を隣の紙と合わせてください。紙の端ではありません
  • 合わせの印（十字と菱形）は、重なった帯の中央にあります。 重ねたときに隣の紙の同じ印とぴたり重なります
  • 線は受け持ち範囲より少し外まで描いてあります。線が続いていることを 目で確かめながら貼れます
  • 全ページが同じ倍率で刷れているかを、それぞれの目盛りで確かめてください。 1枚だけ設定が違うことがあります

型紙がうまく出ない

「用紙に収まりません」と出る

縮めません。次のどれかです。

  • 用紙を大きくする（「A2 なら1枚で収まります」という案内が出ます）
  • 分割して刷る（3×1 = 3枚、のように出ます）
  • シームを増やして、島を小さく分ける
  • 「用紙のまわり」「重ねしろ」を減らす

島の間隔が広すぎる／狭すぎる

「紙に並べる」の アイランド間隔 を変えると、その場で並べ直します。

型紙の形が歪む

UV 展開の性質上、元の形とシームの位置によって歪みます。 円錐や球のように、そもそも平面へ展開できない形では必ず起きます。

どれだけ歪んだかは「4. 出す / 残す」に出ます。

縮み 中央 4.1% / 大きいところ 12.3%

「大きいところ」は、縮みの大きいほうから 5% の辺です。最大値は 出していません。1本だけ極端な辺があっても実害は小さいのに、 数字だけが独り歩きするためです。

大きいところ見かた
5% 未満気にしなくて大丈夫です
5〜15%布ならいせ込みで吸収できます。紙ならシームを足したい
15% 超シームが足りません。曲面を1枚で展開しようとしています

縮む側にしか外れません。 平面へ写す以上、傾いた辺は短くなる ためです。組んだときに出るのは「少し足りない」で、余ることは ありません。

シームを増やして、1つの島を小さくすると軽くなります。

印や文字が消えた

  • 手動で調整（レイアウト編集）の最中は、控えた印をずらして描いています。 頂点を足したり消したりすると、対応が取れなくなるため表示を止めます
  • 「型紙を確定して残す」を押すと、マーキングは消えます（仕様です）

動作が重い

  • 軽量ビュー を入れてください。元モデル側の重い表示を止めます
  • 元モデルを非表示にすると、そちら側の計算をまるごと飛ばします
  • 面数の多いモデル（数百面の島）では、糊代の計算に数百ミリ秒かかります。 一度計算すれば、形と設定が変わるまで作り直しません

糊代・縫い代

糊代が付かない辺がある

次のどれかです。

  • 相手がいない辺 … 元の立体の縁（開いた口など）。貼り合わせる先が 無いので付きません
  • 場所がない … 隣の島やタブとぶつかる。自動で細くし、下限まで 細くしても入らなければ諦めます。無理に置くと、切ったとき型紙自体を 切ってしまうためです
  • 手で消してある … 「全部戻す」で戻ります

糊代が思っていたのと逆の型紙に付く

どちら側に付くかは自動で決まります。その決め方は内部の順序による もので、画面に出ている A / B / C とは関係がありません。

元メッシュを編集モードにしてその辺を選び、反対側へ移す を押して ください。押すと、どの型紙へ移ったかが画面下に出ます（「A → C」）。 移した先に置けない（隣とぶつかる）ときは、元の側のままになり、 移り先も出ません。

どの辺を触ったか分からなくなった

元モデルのシーム線の色を見てください。

色状態
赤そのまま
灰糊代を消した辺
橙反対側へ移した辺

全部戻したいときは「全部戻す」です。

詰まったレイアウトでは、ぶつかって付かないタブが増えます。 「アイランド間隔」を広げると付きやすくなります。

糊代を切ってしまった

根元の破線は折り線です。 切るのは台形の外側の3辺だけです。

画面では色で分かれています（既定は裁断線＝青緑、折り線＝桃）。 刷ると両方とも黒になり、実線と破線で区別します。

なめらか仕上げ（カーブ表示）で出ない

糊代・縫い代はメッシュの辺を単位にしています。カーブにはメッシュの辺が 無いため、どの辺がどのシームかを引けません。なめらか仕上げでは効きません。

三面図

書き出したあと画面が変わっている

戻るはずです。戻っていなければ不具合なので、どの操作の後かを添えて 教えてください。

視点・背景・オーバーレイ・BOX と寸法の表示は、書き出しの間だけ変わり、 終われば必ず元へ戻るようにしてあります。

画像に N パネルやツールバーが写る

写らないように切り抜いています。写っていれば不具合です。

「用紙が大きすぎます」と出る

カスタム用紙が大きすぎます。下限の解像度（96dpi）でも画素数が上限を 超える大きさ（おおよそ 1m × 2.5m 以上）では、メモリが足りなくなるため 断ります。用紙を小さくしてください。

三面図が用紙に収まらない

縮尺の N を大きくしてください（1:2 → 1:5 など）。N が大きいほど図は 小さくなります。用紙を大きくしても構いません。

寸法の文字が図に重なる

寸法位置の微調整 を開くと、面ごと・軸ごとに位置をずらせます。 文字位置をリセット で戻ります。

いまできないこと

型紙

  • 素材の厚みの補正 — 厚みのぶんの寸法調整は入りません
  • SVG 出力 — PDF と PNG のみです
  • 短い辺に糊代を付けない下限の指定 — 曲面のシームでは辺ごとに 1枚ずつ付くので、分割数の多いモデルでは小さなタブが並びます
  • 島の間隔の自動調整 — 糊代を入れても間隔は変わりません。 ぶつかるタブは細くなるか、付きません

三面図

  • 部分の寸法 — 出せるのは外接直方体の縦横高さだけです。 「穴は左端から 40mm」のような寸法は表現できません
  • 線画 — ビューポートを撮っているので、陰影のついた絵になります。 隠線処理・断面・公差はありません
  • 複数用紙への分割 — 1枚に収める前提です（縮尺を落としてください）

共通

  • 元モデルを作り直すと設定が失われる — リトポロジーすると辺の番号が 変わるため、シームも糊代の設定も失われます
  • Blender 4.x での動作は未検証 — 5.2 固有の API は見つかっていないので 下げられる見込みですが、確かめていません

不具合を報告するとき

次があると調べやすくなります。

  • どの操作を押したか（パネルのどの区画か）
  • 画面のスクリーンショット
  • Blender のコンソールに出たメッセージ（ウィンドウ › システムコンソールを切り替え）
  • 可能なら .blend ファイル
