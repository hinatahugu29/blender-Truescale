Truescale — Blender のモデルを、実寸のまま紙へ出すアドオン

コスプレ造形・衣装・紙模型・立体物の制作向けです。
Blender で作った形を、縮尺を掛けずに紙の型紙にします。

無料で配布しています。

────────────────────────────

■ できること

【型紙をつくる】

シームを入れたモデルを、実寸のまま平面へ開きます。

・実寸の型紙メッシュを作る
・合印、番号、文字、上方向の矢印、型紙ID（A/B/C…）を置く
・縫い代（輪郭を外へ広げた裁断線）
・糊代（貼り合わせる辺に付く、折って糊を付けるための台形）
・紙に並べる。1枚に入らなければ複数枚に分割
・PDF（1ファイル）または PNG（300dpi）で書き出す
・型紙を普通のメッシュとして確定して残す

【三面図をつくる】

モデルを囲む箱を作って、外形寸法を表示します。

・箱と寸法を3Dビューへ重ねて表示（モデルを編集すると追従）
・正面・上面・側面・任意の4分割ビュー
・三面を1枚の用紙へ、指定した縮尺で並べた PNG
・1面だけの実寸 PNG

────────────────────────────

■ 縮めません

このアドオンは、用紙に収めるための拡大縮小を一切しません。

収まらないときは、
　・何枚に分割すれば刷れるか
　・どの用紙なら1枚で収まるか
を出します。黙って縮めることはありません。

数パーセント縮んだ型紙は、切ってから気付くことになるためです。

分割したときは、貼り合わせに必要なものが各ページに入ります。

　・受け持ち範囲の枠（隣の紙と合わせる線）
　・合わせの印（重ねると隣の紙の同じ印とぴたり重なります）
　・実寸の目盛り（定規を当てて、縮んでいないか確かめられます）
　・タイル名（1-A、2-A…）と総数

目盛りを必ず入れているのは、印刷設定の「用紙に合わせる」で
数パーセント縮んでも、目では気付けないからです。
定規を当てれば分かるようにしてあります。

────────────────────────────

■ 実寸の基準は自分で決められます

シーンの Unit Scale をそのまま使うほかに、
「このアドオンの中だけで 1 BU を何ミリとして扱うか」を決められます。
シーン側の設定を触りたくないときに。

編集モードで長さの分かっている辺を1本選んで
「選択した辺を基準に実寸を決める」を押すと、
「この辺は 80mm のはず」と入れるだけで基準が合います。

────────────────────────────

■ 動作環境

・Blender 5.2 以降
・入力は Mesh オブジェクト
・追加のインストールは不要です（Blender 同梱のもので動きます）

Blender 4.x では未検証です。5.2 固有の API は使っていないので
動く見込みですが、確かめていません。

────────────────────────────

■ 入れかた

1. ダウンロードした ZIP をそのまま用意します（展開しないでください）
2. Blender の 編集 › プリファレンス › エクステンション を開きます
3. 右上のメニューから「ディスクからインストール」を選びます
4. ZIP を選びます
5. 3Dビューの N パネルに「Truescale」タブが増えます

同梱の manual.html に、使いかたと困ったときの対処をまとめてあります。

────────────────────────────

■ できないこと（先にお伝えします）

・展開の歪み率を数字で見る手段はありません
・素材の厚みぶんの寸法補正は入りません
・SVG 出力はありません（PDF と PNG）
・三面図で出せるのは外接直方体の縦横高さだけです。
　「穴は左端から40mm」のような部分の寸法は出せません
・三面図は線画ではありません。ビューポートを撮っているので
　陰影のついた絵になります。隠線処理や公差はありません
・元モデルをリトポロジーすると、シームと糊代の設定は失われます

無料（0円）。「ブースト」（投げ銭）を受け取るなら、
価格を 0円 にしたうえで「ブースト」を有効にしてください。

### 添付ファイル

```

```

ZIP の中に manual.html（使いかた）と LICENSE が入っているので、
別途の添付は不要です。

### 画像（用意するとよいもの）

1. **1枚目** — Blender の画面に型紙と用紙ガイドが出ているところ。
   何をするものかが一目で分かるもの
2. 刷った型紙の写真、または PDF のページを並べたもの。
   実寸であることが伝わるもの（定規を添えると強い）
3. 糊代・縫い代が付いた型紙のアップ
4. 三面図シートの出力例
5. パネルの全体像（1→2→3→4 の並びが見えるもの）

2枚目の「刷って定規を当てた写真」が、このアドオンの主張
（縮めない）を一番よく説明します。
