## なぜ引き継がずに書き直したか

内容が実際の動きと合わなくなっていた。

- 「複数用紙への分割印刷は未実装です」→ 実装済み（重ねしろ・合わせの印つき）
- 「縫い代・接着代は加味されません」→ 実装済み
- 「SVG出力に対応していません」→ PDF で出せる
- 画素数の上限の数字が、実際の値と違っていた

**間違った説明は、説明が無いより悪い。** 一度そう書いたものを部分的に直すと、
どこまでが最新か分からなくなる。全部書き直した。
