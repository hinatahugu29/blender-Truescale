================================================================

Truescale Draft（製図）
================================

Blenderでの造形作業向けに、Bounding Box・寸法表示・実寸PNG・
三面図シート出力をまとめたツールです。

本アドオンは「造形ヘルパー v2.4.13」を前身とし、名称を変更して
開発を引き継いだものです。バージョン番号は 0.1.0 から振り直しています。

ライセンス: GPL-3.0-or-later（全文は同梱の LICENSE を参照）
Nパネルの「Truescale」タブに追加されます。

※開発中のため、仕様変更や不具合修正が予告なく行われる場合があります。

【主な機能】

・Bounding Box + 寸法表示
・元オブジェクトへの自動追従
・上面 / 前面 / 側面 / 任意ビュー
・BOX / 寸法線のみ / 枠なし の表示切り替え
・寸法単位 mm / cm / m
・寸法文字サイズ・色、枠線色・太さの調整
・図面ビュー / PNG書き出し背景を 白 / グリッド / 黒 / カスタム色 から選択
・上面 / 前面 / 側面 / 任意ビューのPNG書き出し
・上面・前面・側面の3面まとめて書き出し
・3面まとめて書き出しでは縦寸法を90°回転
・実寸基準のPNG DPI情報付与
・図面シートのプレビュー / PNG書き出し
・図面シート用紙 A4 / A3 / A2 / A1 / A0 / カスタム
・図面シート縮率 1:1 / 1:2 / 1:5 / 1:10 / 任意
・図面シートの縦 / 横 / 自動判定
・極端なビューポート拡大・縮小状態からでも、
  書き出し時に自動で表示倍率を正規化
・任意ビューPNGのUI写り込み対策
・「なんかずっと暗いとこ」表示
  暗所中はグリッドとBlender標準X/Y軸も一時非表示
  復帰時は元の表示状態へ戻ります


【図面シートについて】

図面シートは、現在のビューポート倍率に依存せず、
書き出し時に対象を自動でフレーミングします。

上面・前面・側面をBounding Box基準で配置し、
寸法文字は最終シート上へ描画します。

PNGにはDPI情報を書き込みますが、
画像ビューア上の見た目の大きさはソフトによって異なります。

Illustrator等、DPIを保持するソフトで配置し、
印刷時は100%倍率を基準にしてください。

プリンター側の「用紙に合わせる」「フィット」等を使用すると、
物理サイズが変わる場合があります。

重要な造形で使用する前に、
既知寸法のテスト出力で確認することをおすすめします。


【使い方の基本】

1. 対象オブジェクトを選択
2. 「BOX＋寸法を作成」
3. 必要に応じて表示・単位・文字サイズ等を調整
4. 個別PNG、3面まとめて書き出し、または図面シートを使用
5. 図面シートは「プレビュー」で確認後、「書き出し」


【試してくれる方へ】

まだ作者自身も実際の造形作業で使いながら調整している段階です。

変な挙動、見切れ、文字位置、書き出しサイズ、
「こうした方が使いやすい」などがあれば、
スクリーンショットと一緒に教えてもらえると助かります。

Blenderのバージョンと、
「何を押したらどうなったか」が分かると確認しやすいです。
