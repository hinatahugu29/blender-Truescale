Truescale v0.2.0
================================

Blenderのジオメトリを、実寸のまま紙へ出すためのツール群です。
コスプレ造形、衣装、立体物の制作を想定しています。

2つの機能をまとめて提供します。

  Unfold … シーム付きモデルから実寸の型紙（展開図）を作る
  Draft  … Bounding Box・寸法表示・三面図シートを作る

どちらも3DビューのNパネル「Truescale」タブに、
それぞれのパネルとして並びます。使わない方は畳んでおけます。


■ インストール

1. truescale フォルダの中身を ZIP に固めます。
   （blender_manifest.toml が ZIP の直下に来るようにしてください）
2. Blenderを開きます。
3. 編集 > プリファレンス > エクステンション を開きます。
4. 右上メニューから「ディスクからインストール」を選びます。
5. 作成した ZIP を選択します。
6. 3DビューのNパネルに「Truescale」タブが追加されます。


■ 対応環境

- Blender 5.2 以降
- 入力モデルはMeshオブジェクト

※ 5.2 固有のAPIは確認されていないため 4.2 まで下げられる見込みですが、
   未検証のため現在は 5.2 を最低要件としています。


■ 詳しい使い方

  docs/unfold.txt       Unfold（型紙）の使い方
  docs/draft.txt        Draft（製図）の使い方
  docs/KNOWN_ISSUES.txt 既知の問題と回避策


■ 来歴

本アドオンは、別々に作られていた以下の2つを統合したものです。

  型紙ヘルパー カスタムシーン v1.5.6  → Unfold
  造形ヘルパー v2.4.13                → Draft

実寸換算・用紙サイズ・DPI・PNG出力といった処理が両者で重複していたため、
1つのアドオンにまとめました。統合直後の時点では内部の重複はそのままで、
段階的に共通化を進めています。
